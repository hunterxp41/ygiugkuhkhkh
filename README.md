# Snake Game

A classic browser-based Snake game built with pure HTML5, CSS3, and JavaScript. No external dependencies required.

## How to Play

- Use **Arrow Keys** (or WASD) to control the snake
- Eat the red food pellets to grow and increase your score
- Avoid hitting the walls or your own tail
- Press **R** to restart at any time

## Features

- Smooth Canvas-based rendering
- Score tracking with persistent high score (localStorage)
- Increasing difficulty (speed increases every 5 points)
- Modern dark theme with neon glow effects
- Game over overlay with restart option
- Responsive, centered layout

## How to Run

Simply open `index.html` in any modern web browser. No build step or server required.

```
open index.html
```

## Customization Tips

- Adjust `GRID_SIZE` in `script.js` to change the play area resolution
- Modify `INITIAL_SPEED` to change starting difficulty
- Update CSS variables in `style.css` for different color schemes
- Change `SPEED_INCREMENT` to alter difficulty scaling
